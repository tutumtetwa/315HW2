# HW2 – Student Profile Form

A simple client-side form that collects a student's info and renders a live profile preview using vanilla JavaScript.

**Live site:** https://tutumtetwa.github.io/315HW2/

## Features

- Form validation (required fields, min-length intro, etc.)
- Dynamic profile preview generated on submit
- Dropdown for activity/project interest
- Clean, responsive layout

## Tech Stack

- HTML5
- CSS3
- JavaScript (vanilla, no frameworks)

## Files

| File | Description |
|---|---|
| `index.html` | Page structure and form markup |
| `style.css` | Styling |
| `script.js` | Form handling and preview logic |
